# Synvex — Next Gen Interview Preparation System

AI-powered platform for mock interviews, resume-based questions, and performance tracking.

## Tech Stack
- **Frontend** — React.js (Vite)
- **Backend** — Node.js + Express
- **Database** — PostgreSQL
- **Auth** — Firebase
- **AI** — Gemini API

## Setup

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

> Ask Arhan for the `.env` file and paste it inside both `frontend/` and `backend/` folders.
