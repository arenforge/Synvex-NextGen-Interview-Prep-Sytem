# 🚀 Synvex – Next Gen Interview Preparation System

AI-powered interview preparation platform with mock interviews, resume-based questions, AI feedback, and performance tracking.

---

## ✨ Features

- 🔐 Firebase Authentication
- 🎤 AI Mock Interviews (Voice + Text)
- 📄 Resume-Based Question Generation
- 🤖 Gemini AI Answer Evaluation
- 📊 Performance Dashboard
- ⚡ Real-Time Communication using WebSockets
- 🧠 Role-Based Question Bank

---

## 🛠️ Tech Stack

| Frontend | Backend | Database | AI |
|----------|----------|-----------|----|
| React.js (Vite) | Node.js + Express | PostgreSQL | Gemini API, Deepgram |

## ⚙️ Setup

### 🔧 Backend

```bash
cd backend
npm install
npm run dev
```

### 💻 Frontend

```bash
cd frontend
npm install
npm run dev
```
